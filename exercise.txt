Here's how to clearly separate the two different error cases:

    Invalid type (user enters text, letters, symbols etc. → ValueError from int())
    Valid number but out of range (age < 18 or age > 60)

You have two main clean ways to do this:
Best & Most Recommended Solution (2024–2025 style)
Python

try:
    age = int(input("Enter age (between 18 to 60): "))
    
    if age < 18:
        raise ValueError("Age is too young. You must be at least 18 years old.")
    
    if age > 60:
        raise ValueError("Age is too high. Retirement age is considered 60.")
    
    # If we reached here → age is valid
    years_left = 60 - age
    print(f"Years remaining for service = {years_left}")

except ValueError as e:
    # This catches BOTH:
    # 1. int() conversion error
    # 2. Our own raised ValueError with custom messages
    
    error_message = str(e)
    
    if "invalid literal for int()" in error_message.lower():
        print("Error: Please enter a valid number (digits only).")
    else:
        # This is our own custom message for range error
        print(f"Invalid age: {error_message}")

except Exception as e:
    print(f"Unexpected error: {e}")

Alternative Solution – More Explicit (using two exception types)
Python

class AgeRangeError(Exception):
    """Custom exception for age out of valid range"""
    pass


try:
    age_input = input("Enter age (between 18 to 60): ")
    
    try:
        age = int(age_input)
    except ValueError:
        raise ValueError("Please enter a valid number (digits only)")
    
    if age < 18 or age > 60:
        raise AgeRangeError(f"Age must be between 18 and 60. You entered: {age}")
    
    years_remaining = 60 - age
    print(f"Years remaining for service = {years_remaining}")

except ValueError as ve:
    print(f"Input error: {ve}")

except AgeRangeError as re:
    print(f"Range error: {re}")

except Exception as e:
    print(f"Unexpected error occurred: {e}")

Quick Comparison – Which one to choose?
Approach	Pros	Cons	When to use
One try + message checking	Simpler code, fewer classes	A bit hacky (string check)	Small scripts, quick programs
Custom exception class	Very clean separation, professional	Slightly more code	Serious projects, teaching, long-term code
Two separate try blocks	Very clear logic	Nested try is less elegant	When you want maximum clarity

Most people in 2025 prefer the first or second approach.
Very Clean & Popular Style (my personal recommendation)
Python

try:
    age = int(input("Enter your age (18-60): "))
except ValueError:
    print("Error: Please enter a valid number (only digits allowed).")
    exit()   # or continue / ask again

if age < 18:
    print("Sorry, you must be at least 18 years old.")
elif age > 60:
    print("Retirement age is considered 60. No years remaining.")
else:
    print(f"Years remaining in service = {60 - age}")

This last version avoids exceptions for range checking — many Python developers prefer this style because range checks are business logic, not exceptional errors.

Here's how to check if a given date is a Sunday in Python (most common & clean methods):
1. Best & Most Common Way (using .weekday())
Python

from datetime import datetime, date

# Method A: Using date.today() - check today
today = date.today()
if today.weekday() == 6:
    print("Today is Sunday")
else:
    print("Today is not Sunday")


# Method B: Check any specific date
date_to_check = date(2025, 12, 25)          # Christmas 2025 example
# or
# date_to_check = datetime(2025, 7, 13).date()

if date_to_check.weekday() == 6:
    print(f"{date_to_check} is Sunday")
else:
    print(f"{date_to_check} is NOT Sunday")

Quick reference: weekday() values
Value	Day
0	Monday
1	Tuesday
2	Wednesday
3	Thursday
4	Friday
5	Saturday

2. More readable names (using calendar or strftime)
Python

from datetime import date
import calendar

today = date.today()

# Option 1: using calendar
day_name = calendar.day_name[today.weekday()]
print(f"Today is {day_name}")
if day_name == "Sunday":
    print("→ It's Sunday!")

# Option 2: using strftime (very readable)
day_name = today.strftime("%A")   # → "Sunday", "Monday", etc.
if day_name == "Sunday":
    print("Yes, it's Sunday")

3. One-liner / function style (most reusable)
Python

from datetime import date

def is_sunday(dt=None):
    if dt is None:
        dt = date.today()
    return dt.weekday() == 6

# Usage examples:
print(is_sunday())                          # today
print(is_sunday(date(2025, 7, 13)))         # True (example Sunday)
print(is_sunday(date(2025, 7, 14)))         # False
